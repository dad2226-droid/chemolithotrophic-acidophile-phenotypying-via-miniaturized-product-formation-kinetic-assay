# Chemolithoautotrophic acidophile phenotyping via miniaturized product-formation kinetic assay

This repository contains experimental data, documentation and eight main figures for a microplate-based product-formation kinetic assay for iron- and sulfur-oxidizing acidophiles.

- [Data and experimental documentation](data/README.md)
- [Main figures and captions](plots/README.md)
- [All main figures as one PDF](plots/main_text_figures.pdf)

The data cover indicator calibration, medium validation, biological microplates, flask cultures and test-tube cultures. Family READMEs and accompanying YAML files define methods, units, concentrations, experimental units, controls and sampling times. Shared materials, strains and medium formulations are documented in the [materials and strains catalog](data/00_materials_and_strains/README.md).

Absorbance and product-formation measurements are proxies for metabolic activity; they do not directly measure viable biomass. Interpret repeated observations, shared initial references, missing values and instrument flags using the relevant experimental documentation.
